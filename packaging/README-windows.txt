V ImGui examples — Windows 10/11, x64

Extract the whole archive and open:
  widget_gallery.exe
  implot_dashboard.exe
  glfw_vulkan.exe

ImGui/ImPlot, GLFW, the Vulkan loader, and the Microsoft Visual C++ runtime
DLLs are included beside the applications. No compiler, SDK, or separate
Visual C++ runtime installation is needed. Keep the whole folder together.

A Vulkan-capable graphics driver and a graphical Windows desktop are
required. Windows system DLLs and the device's graphics driver are supplied
by the operating system. VARIANT.txt identifies the ImGui variant.
Third-party license notices are in licenses/.
